# 历史兼容代码清理清单与数据影响

本次范围以用户最终要求为准：只清理历史版本兼容代码，保留当前版本号及现有取值，不清理或重置版本。不部署、不操作运行数据库。

## 调整清单

| 调整项 | 当前行为 |
| --- | --- |
| Codex manifest 的旧客户端版本裁剪 | 所有客户端取得相同的当前模型能力；保留当前 profile 的版本字段 |
| 顶层 `functions/function_call` 自动转换 | 明确拒绝，调用方使用 `tools/tool_choice`；当前工具续链保留 |
| Codex 账号加载时修补旧模式、缺失 seed、并发上限 | 只校验和读取当前记录，非法或缺失必需字段报错，不自动写回 |
| 历史逐账号客户端 profile 合并 | 删除旧字段与合并路径，只读取当前独立加密共享身份记录 |
| 无来源额度冷却推断及旧时间精度补偿 | 恢复只使用明确的当前来源和时间证据，不按旧记录形状推断 |
| ChatGPT Web 账号设备标识自动补齐 | 新建账号时生成，保存成功后才发布；加载缺失标识的记录报错；畸形标识继续隔离并保留原值 |
| 临时聊天的旧账号绑定执行器及旧调用形态 | 统一当前 feature 执行器；旧会话可读，继续发送明确提示新建会话 |
| 无当前调用方的按 token 管理事件及指定账号文本续接 | 删除旧事件、处理器和专用 helper；当前账号管理按稳定 ID 执行 |
| 指标上报旧接口与可选转换等级兜底 | 统一当前带转换等级的接口，同步所有调用方 |
| 平铺交互归档目录兼容 | 只读写按 API Key 分区的目录；不扫描、改写或删除旧平铺归档 |
| Admin 图片接口旧 `owner_id` 范围及测试兜底 | 使用 `api_key_id`，省略时为 `builtin-local`，统一验证范围存在，写请求拒绝未知字段 |
| 图片旧执行路径遗留 helper 和 `failed` 状态别名 | 删除无调用 helper，只识别当前任务状态；正常失败恢复轮询保留 |
| 生产代码中的自动测试 Key 与测试辅助文件 | 测试身份由测试显式建立，辅助代码只参与测试构建 |
| 管理页旧地址与旧状态别名 | 删除旧 `chatgpt/codex` hash 跳转、`owner_id` 范围解析及隐藏导航，只使用当前地址和状态 |
| 基础规范和维护文档 | 根目录 `AGENTS.md` 固化单一当前合同，取消强制升版要求 |

## 数据库影响

数据库表结构、当前加密封装、凭据密钥及派生规则、Bundle 格式版本均不修改。当前有效账号及其加密凭据、独立共享身份及已有用量数据继续使用；启动不再执行兼容性补齐或写回。

存在明确的读取边界变化：Codex 记录若仍使用已删除模式、缺少模式或必要 seed、并发上限为零，或 Web 记录缺少设备标识，将拒绝加载。若部署库仍有这些旧记录，启动会报错，不能据此声称任意历史库均可直接使用。未读取或修改实际部署库，本次确认依据为仓库合同及隔离数据库回归。

历史账号绑定临时会话保留原行及消息，可查看、删除；不再恢复旧执行器继续发送。缺少明确额度来源的冷却不再自动推断为可清理的额度状态，保留到当前调度规则允许解除。

## 回归证据

- Codex `current_contract_test.go`：当前记录重启后加密载荷、seed、模型快照版本与共享客户端版本不变；旧字段拒绝后载荷、更新时间与位置不变。
- Web `device_identity_test.go`：缺失设备标识拒绝后不改写载荷；现行设备身份跨重启保留，畸形值不旋转且不影响健康账号；四种创建入口保存失败时均不发布新账号和设备身份，存储恢复后可重试并跨重启保留身份；凭据替换失败不改变原账号、凭据别名、并发占用或目录版本。
- 临时聊天 `current_contract_test.go`、`feature_execution_test.go`：旧会话拒绝发送前不插入消息、不改变原行；当前完成、取消、历史消息及附件仍通过统一执行器处理。
- 代理 `current_contract_test.go`：版本查询不裁剪能力，旧函数字段明确拒绝，构造函数不生成测试凭据。
- 既有加密存储、Bundle、最终数据库 schema、账号隔离、配额恢复、归档和指标回归继续执行。
